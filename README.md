# University Club Database System

This project is a relational database designed to manage students, clubs, memberships, events, and attendance.

## Features
- Structured database schema with multiple related tables
- Use of primary and foreign keys to maintain data integrity
- SQL queries for analysing membership, attendance, and revenue
- View created for simplified reporting

## Files
- schema.sql → database structure
- queries.sql → analysis queries

## Technologies
- SQL
- Relational Database Design

## Overview
This project demonstrates how a real-world system (student clubs and events) can be modelled using a structured relational database and queried to generate useful insights.
